# Portfolio Website

A modern React + Vite portfolio website showcasing projects, experience, skills, certifications, and contact information.

## Features
- Responsive portfolio homepage
- Project showcase and detail pages
- Experience, skills, and education sections
- Dark/light theme support
- Animated UI transitions

## Tech Stack
- React
- Vite
- Framer Motion
- React Router
- React Icons

## Getting Started
1. Install dependencies
   ```bash
   npm install
   ```
2. Start the development server
   ```bash
   npm run dev
   ```
3. Build for production
   ```bash
   npm run build
   ```

## Deployment
This project can be deployed to GitHub Pages, Vercel, Netlify, or any static hosting provider.
